# Amore Cost

A costing & pricing calculator for Philippine small/medium businesses.
The v0 calculator is real, working code — free, no signup, saved to
your browser only.

```bash
npm install
npm run dev   # http://localhost:3003
```

Full context lives in [CLAUDE.md](CLAUDE.md) and the ICM knowledge
workspace at [docs/](docs/CLAUDE.md) — start with

now. [MASTER-PLAN.md](MASTER-PLAN.md) is a single-file reading copy of
the full roadmap and marketing plan, for quick reference — the `docs/`
files it's drawn from remain the source of truth.
