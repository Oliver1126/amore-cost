# Amore Cost

Recipe costing and menu pricing for Philippine food businesses — five
pages (Dashboard, Input, OPEX & Overhead, Receipt Simulator, Margin &
POS Simulator). Free, no signup, saved to your browser only. Live at
https://amore-cost.vercel.app (redeployed manually with `vercel --prod`).

```bash
npm install
npm run dev   # http://localhost:3003
```
