# marketing/

**Different from [../business/go-to-market.md](../business/go-to-market.md):**
that file is the *strategy* — the offer, the channels, the sales
motion, why each one was picked. This folder is *execution* — the
actual checklist and content backlog for carrying that strategy out.
One fact, one home: don't restate the strategy here, link to it.

**Contains:**
- [launch-checklist.md](launch-checklist.md) — turns
  [../roadmap/roadmap.md](../roadmap/roadmap.md)'s Stage 0 (launch-ready)
  and Stage 1 (validate with 20 owners) into a step-by-step list, with
  the go/no-go gate set before posting anything.
- [content-ideas.md](content-ideas.md) — a backlog of how-to-price/
  how-to-cost content pieces for the roadmap's Stage 2 content engine
  — a queue, not a commitment; nothing here is written yet.
- [free-tier-benefits.md](free-tier-benefits.md) — the actual "why is
  this free" explanation, both the user-facing benefits and the
  business rationale, doubling as ready-to-use messaging if anyone
  ever asks.
- [drafts/](drafts/) — finished (not yet reviewed-and-moved) content
  pieces, written by the `mwp-matrix/` pipeline one at a time from
  `content-ideas.md`'s backlog, gated behind a human approval step
  before they land here. Once you're happy with a draft, per
  `content-ideas.md`'s own rule, move its matching bullet out of the
  backlog — the draft file staying here *is* that "it's written" state.

**Reads:** [../business/concept.md](../business/concept.md) for who
the ICP actually is before writing any copy — every piece of content
or checklist item here should trace back to that audience, not be
generic small-business content.

**Human check:** none of this has been executed yet — the launch
checklist is still sitting at step 1 (go/no-go criteria), same as
`next-steps.md`'s standing "validation is overdue" note. Building more
marketing material doesn't substitute for actually posting the pitch.
