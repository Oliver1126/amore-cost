[../business/market-research.md](../business/market-research.md) before

from the free no-signup v0 calculator through the paid-tier v2
differentiators. Once code exists, this is where an `overview.md` /
`architecture.md` pair (mirroring Atlas Freelance's `product/` folder)
would get added — not created yet since there's nothing built to
document.

**Human check:** this is a draft scope, not a spec — no line item here
has been validated with a real user yet (see the open questions in
`../business/concept.md`).
