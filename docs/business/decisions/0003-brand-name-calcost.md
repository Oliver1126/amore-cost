# Brand name is Calcost, not RepricedIQ

## Context
[0002](0002-brand-name-repricediq.md) picked RepricedIQ, flagging a real
risk: "Repricer" is an established SaaS category name (Amazon/Walmart/
eBay/Shopify competitive dynamic-pricing tools) that does a different
job than this product. Separately, Oliver floated "Calcul" and "Calcost"
as short-for-"calculator" alternatives.

## Decision
**Calcost** ("calc" + "cost"). Folder renamed from `RepricedIQ/` to
`Calcost/` to match.

## Why
Between the two "Calc-" alternatives, Calcost was clearly the stronger
option: it directly names the core mechanic (calculating your true
cost) rather than reading as a truncated, ambiguous word the way "Calcul"
does, and it avoids RepricedIQ's specific problem — a search turned up
no meaningful brand collision, only an obscure Node.js developer library
of the same name (negligible real-world confusion risk). It also sheds
the "repricer" category-confusion risk entirely, since nothing in the
competitive-dynamic-pricing space uses "Calc-" naming.

## Consequences
- Still owes the same due-diligence checklist as 0002 never finished:
  `.ph`/`.com` domain, social handles, and an IPOPHL trademark search
  specifically for "Calcost" haven't been run.
- Like RepricedIQ, this is an English/neutral name — it doesn't do the
  "built for Filipino business owners" positioning work a name like
  Kwenta or TuboKo would have for free (see
  [../../branding/options.md](../../branding/options.md)). Unchanged
  tradeoff from 0002, just restated: the product/marketing copy has to
  carry that positioning instead of the name.
- Like RepricedIQ, "Calcost" names the *cost* half of the job but not
  the *pricing/margin* output half — a smaller naming gap than
  RepricedIQ's category-collision problem, not a new one.
