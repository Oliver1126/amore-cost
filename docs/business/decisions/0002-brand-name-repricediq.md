# Brand name is RepricedIQ

## Context
[branding/options.md](../branding/options.md) shortlisted ~26 candidates
across a Filipino-word direction (Kwenta, TuboKo, etc.) and an
English/neutral direction (Marginly, Repriced, MarginIQ, etc.). Needed
one final name to start building under; the workspace folder itself
still carried the placeholder name "Business Calculator."

## Decision
**RepricedIQ** — a mashup of two English/neutral candidates from the
shortlist ("Repriced" + "MarginIQ"). Folder renamed from
`Business Calculator/` to `RepricedIQ/` to match.

## Why
Oliver's call, made directly rather than from the Filipino-word
direction the shortlist's own recommendation (Kwenta) leaned toward.

## Consequences
- **Flagged, not blocking:** "Repricer" is an established, crowded SaaS
  category name for Amazon/Walmart/eBay/Shopify *competitive dynamic
  pricing* tools (Repricer.com, RepricerExpress, SellerSnap,
  StreetPricer, AlphaRepricer) that automatically chase competitors'
  prices in real time — the opposite job from this product (protecting
  *your own* margin from *your own* cost basis, not price-matching
  competitors). "RepricedIQ" risks being misread as belonging to that
  category by anyone who's shopped for e-commerce tools before. Worth a
  direct check — search "RepricedIQ" and "repricer" together — before
  finalizing marketing copy, so the landing page can pre-empt the
  confusion in the first line if needed.
- Loses the PH-first "built for you" positioning work a Filipino-word
  name (Kwenta, TuboKo) would have done for free, given the wedge
  against Craftybase/MarketMan in [market-research.md](../business/market-research.md)
  was specifically "peso-first, not generic-international-sounding."
  Not fatal — the product, pricing, and marketing copy can still carry
  that positioning — but the name itself won't do any of that work.
- Still owes the due-diligence checklist in `branding/options.md`
  ("Before locking a name"): `.ph`/`.com` domain, social handles, and an
  IPOPHL trademark search haven't been run against this specific name
  yet.
