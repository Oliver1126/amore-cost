# branding/

**Start here:** [options.md](options.md) — the full name shortlist,
taglines, and early visual/voice direction.

**Reads:** [../business/concept.md](../business/concept.md) (who the
audience actually is) before adding new name candidates — a name only
works if it survives being said out loud by the target user, per the

AI-image-generator prompts for a visual mark — not yet generated,

pitch design, with the actual page at `pitch-one-pager.html`).
