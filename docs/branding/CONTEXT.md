# branding/

**Start here:** [options.md](options.md) — the full name shortlist,
taglines, and early visual/voice direction.

**Reads:** [../business/concept.md](../business/concept.md) (who the
audience actually is) before adding new name candidates — a name only
works if it survives being said out loud by the target user, per the
"before locking a name" checklist at the bottom of `options.md`.

**Contains:** naming candidates across two directions (Filipino word vs.
English/neutral), tagline drafts, the due-diligence checklist (domain,
social handles, IPOPHL trademark search) that has to clear before any
name is locked, [logo-prompts.md](logo-prompts.md) (superseded
AI-image prompts — the shipped mark is decisions 0010/0011,
`public/brand-mark.png`), and [pitch.md](pitch.md) (the one-page
pitch design, with the actual page at `pitch-one-pager.html` — its copy
is stale, see pitch.md's Status). `design/SKILL.md` is a copy of the
generic build-site skill, not an Amore Cost brand guide; the app's real
UI rules are `../../DESIGN.md`.

**Human check:** the name is chosen (**Amore Cost**, see
[../business/decisions/0009-brand-name-amore-cost.md](../business/decisions/0009-brand-name-amore-cost.md),
which supersedes the earlier choice of Calcost — see
[0003](../business/decisions/0003-brand-name-calcost.md), which itself
superseded the brief initial choice of RepricedIQ) but the
domain/handle/trademark checks in `options.md` have not actually been
run against it yet — that decision record flags this as still
outstanding, and the [roadmap](../roadmap/roadmap.md) lists it as a
Stage 0 task.
